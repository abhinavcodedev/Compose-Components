# Compose Components Design System

A reusable Jetpack Compose Material3 UI component library built for scalable Android applications.

## Features

- Material3 Design System
- Reusable UI Components
- Custom Typography System
- Centralized Theme Management
- Reusable Buttons
- Reusable TextFields
- Reusable Cards
- Dialog Components
- Toolbar Components
- Search Bar
- Loader Components
- Navigation Compose Setup
- Preview Support
- Fake Data Support
- Scalable Folder Structure

---

## Tech Stack

- Kotlin
- Jetpack Compose
- Material3
- Navigation Compose
- Coil

---
